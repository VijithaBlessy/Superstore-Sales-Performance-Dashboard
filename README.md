# Superstore Sales Performance Dashboard

## Project Overview
This project is an interactive Sales Performance Dashboard created using Microsoft Power BI. It helps analyze sales performance based on region, product category, and monthly trends using the Sample Superstore dataset.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)
- **Total Sales:** 2.30M
- **Total Profit:** 286.40K
- **Total Quantity:** 37,873

### 2. Visualizations
- **Sales by Region:** Compares sales across West, East, Central, and South.
- **Sales by Category:** Analyzes sales across Technology, Furniture, and Office Supplies.
- **Monthly Sales Trend:** Displays sales variations over time.

### 3. Interactive Filters
- Region Slicer
- Category Slicer

Users can select different regions and categories to explore sales performance interactively.

## Key Insights
1. West region has the highest overall sales.
2. Technology is the highest-selling category.
3. Sales performance varies across different months.

## Tools Used
- Microsoft Power BI Desktop
- Sample Superstore Dataset

## Conclusion
This project provides an interactive way to analyze sales performance and understand business trends. It helps users compare regional sales, product categories, and monthly performance.
